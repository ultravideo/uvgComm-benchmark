# uvgcomm-benchmark


This repository containes benchmark script for uvgcomm. 

## Usage

Git clone uvgComm from https://github.com/ultravideo/uvgComm.git. Install docker. 

Please edit the necessary locations at the start of the 'experimental_evaluation.sh' file. You can also edit the tests if so desired. Download used test files.

Then run the script file:
```
./experimental_evaluation.sh
```


## Used in

ACM Transactions on Multimedia (TOMM) special issue called Methodologies for Multimedia (Meet4MM).
